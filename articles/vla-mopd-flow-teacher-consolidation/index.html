基本信息与一句话总结

原文 VLA-MOPD: On-Policy Distillation for Multi-Task VLA Policy Consolidation，Yongxuan Lv、Zhen Fang、Lichen Man 等。arXiv 2026-11-09 首次提交，实际阅读 2611.12286v1（v1 同日）。近期补读，整理及最近实质修订 2026-11-14。已读方法、实验、消融、局限和附录，核对公开分支；未独立复现。

一句话：学生负责访问环境并生成自己的去噪链，路由到的冻结专家只在学生当前的中间状态上指出下一步，从而把多个专长合进一个流匹配 VLA。

问题、方法与关键公式

多任务混合 RL 要从稀疏任务结果为策略分配信用；直接离线克隆又缺少学生部署时访问的状态，且只给最终动作。VLA-MOPD 分清两个分布：外层是学生实际见到的机器人观测与指令，内层是以该观测为条件，学生从噪声到动作块经过的 ODE 状态。冻结当前学生快照采集两者，再用指令选择冻结专家标注所有有效动作块，包括失败回合里的有效部分；专家不接管机器人，也不从自己的随机噪声另走一条轨迹作为逐步标签（§3–4.2、图 1、算法 1）。

令第 k 次 Euler 步为 μθ = xk − δk vθ(xk, sk, c)。在相同 xk, sk, c 处，教师均值与学生均值之差只剩速度场误差乘步长；损失为每个有效动作元的均方误差，等价于按 δk² 加权的速度匹配。对共享协方差的高斯，均值误差可以精确写成 KL；对实际的确定性 Euler 采样，则是回归代理，不能称两个不同 Dirac 转移之间的有限 KL。教师与学生分别计算 VLM 前缀，在统一归一化动作坐标下预测；训练更新学生 VLM LoRA 和整个动作专家，不对已存储现场状态、教师标签或采样分布反传。每轮更新后刷新快照。

保留旧能力时，额外在保留任务的学生状态上匹配初始学生的步均值，损失为 L = L_teacher + β L_ref，不要求这些任务另有更强教师，初始环境也可提供保留观测（§4.3、附录 A–B）。与 REPAIR §4.3 同样利用学生访问状态，但 REPAIR 对候选最终动作块按 critic 分数加权，再做 flow matching；MOPD 需要能够在同一个带噪动作块上查询教师的速度，并不把 Q 值当内层导数。

证据、消融与适用边界

LIBERO 四套各 500 回合、一个训练种子，指标为回合内至少一次成功。学生每任务一条示范 SFT 的四套均值是 75.4%，路由 PPO 教师 98.5%。同样由学生访问状态，最终动作蒸馏为 98.15%（表 1 舍入为 98.2%），逐步匹配为 98.9%（表 1、§5.3）。能隔离内层监督的差值是约 0.75 个百分点，不是初始策略到最终策略的全部差；四套中 Object 略下降。教师本身来自已训练或另适配的 PPO，不能理解为全部方法只使用一条轨迹，也不能从每优化步的收敛曲线推断总训练成本更低。

保留消融在同一 LIBERO 协议下改进 Spatial、保留 Object。Object 从初始 95.6% 降到有保留项 92.6%、无保留项 82.4%；对应 Spatial 分别 96.6% 和 98.0%，作者选的是 Spatial 接近而非完全相同的检查点（图 3a）。RoboTwin 2.0 双臂三任务各 100 回合，初始学生 / 蒸馏学生 / 路由教师为 73.0/89.3/94.0%（表 2）；无同协议终点蒸馏对照，不能把改善归给逐步项。Piper 单臂三任务各 30 次，三者均值 70.0/90.0/93.3%；该处教师为单任务 SFT 学出，学生每任务两轮各 50 条 rollout，30 Hz；训练预测并执行 50 步，评测预测 50 只执行前 25 步（表 3、附录 C），不是部署 RTC 的对照。

作者指出教师训练和维护成本随任务规模增长，能力上限依赖路由教师的覆盖与质量。进一步的分析边界：单种子、成功一次指标和预定义路由均不足以证明多任务长期稳定性；还应报告教师每个去噪步的标注成本与可能的负迁移。

开放程度、迁移与面试

作者的 VLA-MOPD 仓库 有 libero-opd 分支，可查到 OPD worker、LIBERO 训练配置与参考路由测试。公开代码不代表本文所有教师、学生、Piper 真机权重与数据均可下载；本次没有核验到明确对应真机表 3 的权重和数据。原始资源：版本记录 · 固定全文。

迁移建议（待验证）。 X5 不改现有 z_rl + proprio + ref_chunk、C=10 和 RTC 的 H=30、D=5–6、blend=4。先用同一批学生状态、相同数据帧数和 Q 查询预算比较执行动作克隆、候选 Q 加权、Q 加权加原策略保留；Joint、EEPose 分开统计并分别归一化。TD3 actor 输出残差动作块，不能直接充当教师速度场。只有另训可在共享动作用噪声状态上查询的 flow 教师后，才做严格的终点/逐步对照：固定教师、训练更新数和学生 rollout 数，单列专家标注 GPU 小时。用插接成功、旧任务退化、干预率、峰值力和端到端 P99 为主，先仿真及影子，真机保留限速、力阈和人工接管；不能把仿真样本效率当真机安全证据。

面试追问。 学生已在正确的相机观测上训练，为什么还会遇到内层分布偏移？若只比较离线 BC 和逐步蒸馏会混掉哪两个变量？什么时候同一中间状态上的均值匹配才等于 KL？
